# KAIRO — Intelligence that automates.

> **Describe what you want to achieve. Kairo understands your intent and transforms it into intelligent automation.**

KAIRO is an AI-powered Smart Automation workspace designed for modern product teams, founders, and enterprises. It bridges the gap between natural language intention and live, production-grade autonomous workflows.

Developed as a flagship prototype for the **Smart India Hackathon**.

---

## 🌟 Key Features

1. **Natural Language Direct Synthesis**: Describe any workflow in plain English; Kairo identifies triggers, structures logic branches, and maps integrations automatically.
2. **Visual Workflow Canvas**: Interactive SVG bezier flow workspace with live node dragging, zooming (70% - 160%), and parameter configuration.
3. **Multi-Node Test Execution**: Step-by-step simulated test runs with live latency measurements, green status checks, and a real-time runtime log console.
4. **Autonomous Activation**: One-click deployment with activation celebration, live cloud listener simulation, and instant status updates.
5. **Full Workspace Navigation**: 9 dedicated navigable screens (Landing, Overview, Create Automation, Workflow Canvas, Automation Library, My Automations, Analytics, Live Activity, and Settings).
6. **Apple & Linear-Inspired Light Design System**: Strict light-mode palette, 8px rhythm grid, soft white surfaces, and subtle micro-interactions built with Framer Motion.

## 🚀 Quick Start

### Prerequisites
- Node.js (v18+)
- npm or pnpm

### Installation

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production deployment
npm run build
```

The prototype will be live at `http://localhost:5173/`.

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS (custom Kairo design tokens)
- **Animation**: Framer Motion
- **Icons**: Lucide React
- **Celebration Effects**: Canvas Confetti
